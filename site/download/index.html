Up and running in a minute

Three steps, then it’s one keypress away for good.

  1. 1

    Run the installer

    Open RvgeShot-Setup.msi from your downloads. If Windows says “Windows protected your PC”, click More info → Run anyway. RvgeShot isn’t code-signed yet — that’s all the warning means.

  2. 2

    Find it in your tray

    Launch RvgeShot from the Start menu. It runs quietly in the system tray next to the clock — click the icon for your gallery, right-click for capture, recording and settings. It starts with Windows (you can switch that off).

  3. 3

    Shoot & record

    PrintScreen captures a region, Ctrl + Shift + R records one to MP4 or GIF. Change either in Settings → Hotkeys.

Tip: if PrintScreen opens the Windows Snipping Tool instead, turn off Settings → Accessibility → Keyboard → Use the Print screen key to open screen capture.

Free — and staying free

No ads, no account, no tracking inside the app. If RvgeShot saves you time, chipping in keeps the updates coming — macOS, private share links and more.
